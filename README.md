# Bed Finder

Aplikasi web sederhana berbahasa Indonesia untuk mencari tipe tempat tidur berdasarkan nomor kamar.

## Cara memasang di iPhone
1. Unggah semua file ke GitHub.
2. Aktifkan GitHub Pages.
3. Buka alamat GitHub Pages melalui Safari.
4. Tekan tombol Bagikan.
5. Pilih **Tambahkan ke Layar Utama**.

Aplikasi dapat digunakan tanpa internet setelah dibuka satu kali.

## Catatan data
- Data ditranskripsikan dari tabel “침대 배치 현황” bertanggal 2025-01-31.
- Nomor kamar 1122 ditetapkan sebagai `S+S`.
- Kolom paling kanan (`327`, `427`, ..., `1127`) ditetapkan sebagai kamar `Suite`.
- Warna antarmuka hanya memakai warna netral, abu-abu, dan biru muda yang tampak pada tabel asli.
